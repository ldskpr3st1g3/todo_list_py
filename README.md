# Task Tracker — Трекер продуктивности

## Описание
Консольное приложение для учёта задач, времени их выполнения и оценки общей продуктивности дня.

## Предметная область
Основные объекты:
* `Task` — отдельная задача с длительностью и статусом выполнения.
* `ProductivityTracker` — коллекция задач за день с методами расчёта статистики и формирования отчёта.

## Классы

### Task
**Атрибуты:**
* `task_id` (int) — уникальный идентификатор задачи.
* `duration` (int) — длительность задачи в минутах.
* `is_completed` (bool) — статус выполнения.

**Методы:**
* `__init__` — конструктор объекта.
* `mark_completed()` — меняет статус на выполненный.
* `__str__` — строковое представление задачи.
* `to_dict()` / `from_dict()` — сериализация и десериализация для JSON.

### ProductivityTracker
**Атрибуты:**
* `date` (str) — дата отчёта.
* `tasks` (List[Task]) — список объектов задач.

**Методы:**
* `add_task()` — создание и добавление новой задачи в коллекцию.
* `get_total_tasks()`, `get_completed_tasks()` — подсчёт задач.
* `get_total_minutes()`, `get_completed_minutes()` — подсчёт времени.
* `calculate_completion_percent()` — расчёт процента выполнения.
* `get_productivity_grade()` — текстовая оценка продуктивности.
* `print_report()` — вывод форматированного отчёта в консоль.
* `to_dict()` / `from_dict()` — работа с JSON.
